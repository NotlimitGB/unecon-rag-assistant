# Task023B — текущая политика grounded-answer-v2

## Root cause and v2 decision

V1 разрешал отвечать по связанным общим сведениям, даже когда вопрос требовал персонального прогноза или выбора. В v2 добавлена явная граница ответимости: индивидуальные прогнозы, неустановленные будущие сведения, личные/оперативные статусы, будущие назначения и персональные рекомендации требуют отказа. Общие фактические вопросы остаются допустимыми. Все защиты контекста и прежняя JSON-схема сохранены.

Нет правил по ключевым словам, классификатора, исключений для вопросов или дополнительного LLM-вызова. Поиск, `qwen3.5:9b`, температура 0.1, 512 токенов и `think=false` неизменны. Исторические Task011/018/020 относятся только к v1. Проверки исторических экспериментов отклоняют активный v2, не маркируя его ошибочно как v1.

Решение: [ADR 0006](../decisions/0006-explicit-answerability-policy.md). Один полный v2-прогон выполнен 2026-09-26 на рабочем дереве поверх Task022; повторной генерации отдельных вопросов для подбора успешного ответа не было.
