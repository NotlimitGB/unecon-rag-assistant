# Протокол ручной оценки ответов Task018

## Назначение и граница свидетельств

Оценщик вручную рассматривает 16 ответов эксперимента Task018. Инженерный вердикт `diversity_integration_promising`, попадание в источник или страницу, наличие числового токена и корректная структура ответа сами по себе не являются оценкой фактической правильности.

Для оценки разрешены только замороженные эталонные факты, примечание датасета, точный ответ Task018, пять точных официальных контекстов, переданных генератору, и его цитаты. Веб-поиск, внешние знания и ответы старого baseline не используются для исправления или дополнения свидетельств. Если эталон конфликтует с официальным контекстом, оценщик отмечает `needs_gold_review: true` и объясняет это в `review_note`; датасет остаётся неизменным до отдельного решения.

## Оценки 0–2

Четыре оценки ставятся только для 15 случаев со статусом `answered`. В каждом пункте **2** означает полное соответствие, **1** — частичное, **0** — существенную проблему.

| Критерий | 2 | 1 | 0 |
|---|---|---|---|
| `factual_correctness` | Все существенные факты согласуются с эталоном и официальными контекстами; нет ошибочных чисел, дат, условий или оговорок. | Суть верна, но есть незначительная неточность, неполная оговорка или иной нефатальный дефект. | Существенное утверждение неверно или противоречит свидетельству, либо неверен основной ответ. |
| `faithfulness` | Каждое существенное фактическое утверждение прямо подтверждается предоставленными официальными контекстами. | Основные утверждения подтверждены, но второстепенное утверждение или вывод не подтверждается напрямую. | Существенное утверждение не подтверждается контекстами или противоречит им; внешние знания не заменяют свидетельство. |
| `completeness` | Ответ охватывает существенные эталонные факты и важные оговорки, необходимые для вопроса. | Основной ответ есть, но отсутствует существенная деталь или оговорка. | Отсутствует запрошенная основная информация или вопрос по существу не раскрыт. |
| `citation_support` | Процитированные контексты прямо подтверждают все существенные утверждения, требующие подтверждения. | Цитаты подтверждают суть, но существенная деталь подтверждена слабо, косвенно или лишь неприведённым контекстом. | Цитаты не подтверждают существенное утверждение, указывают на неверное свидетельство или отсутствуют там, где нужны. |

## Достаточность контекста и отказ

Поле `context_sufficiency` заполняется для всех 16 случаев:

- `sufficient`: пять предоставленных контекстов достаточны для материально правильного ответа;
- `insufficient`: пяти контекстов недостаточно;
- `unclear`: по ним нельзя уверенно решить вопрос достаточности.

`gen-012` остался отказом `insufficient_evidence`, хотя замороженный датасет ожидает ответ. Его контексты оцениваются человеком, но четыре оценки качества содержательного ответа остаются `null`. Несуществующему ответу не присваиваются искусственные семантические баллы. При необходимости оценщик ставит флаг проверки эталона и оставляет заметку.

## Порядок работы

Из каталога `backend/`:

```powershell
python -m app.experiments.table_aware.human_review_cli prepare
python -m app.experiments.table_aware.human_review_cli validate --partial
```

Первая команда сверяет хеши датасетов и обоих локальных отчётов Task018, проверяет 16 ответов, 80 результатов поиска, 17 условий, все пять контекстов на случай и связи цитат. Она создаёт игнорируемые Git файлы `data/processed/evaluation/pdf_page_diversity_human_review.json` и `.md`. JSON является источником введённых человеком оценок; Markdown удобен для чтения. Повторная подготовка не перезаписывает изменённый JSON.

Оценщик вписывает `reviewer_name`, `reviewed_at`, при желании `reviewer_note`, затем `context_sufficiency` для каждого случая и четыре целых числа 0–2 для каждого содержательного ответа. `needs_gold_review` и `review_note` используются для спорного эталона или пояснения. Нельзя менять вопрос, эталон, ответ, контексты, цитаты или SHA-256 исходных отчётов.

После редактирования:

```powershell
python -m app.experiments.table_aware.human_review_cli validate --partial
python -m app.experiments.table_aware.human_review_cli summarize --partial
```

Частичная сводка использует только полностью оценённые ответы, показывает число заполненных/частичных/нетронутых случаев и не подставляет оценки в пустые поля. Для завершённой оценки:

```powershell
python -m app.experiments.table_aware.human_review_cli validate
python -m app.experiments.table_aware.human_review_cli summarize
```

Полная проверка требует имени и даты оценщика, `context_sufficiency` для всех 16 случаев и четыре оценки для 15 ответов; у отказа они должны остаться `null`. Полная сводка записывается только локально в игнорируемый `pdf_page_diversity_human_review_summary.json`. Она выводит средние, распределения 2/1/0, полностью чистые ответы, нулевые оценки, достаточность контекста, отказ и флаги проверки эталона. Она не выдаёт вердикт о внедрении.

## Защита от смещения

Порядок 16 вопросов заморожен. Старые ответы Task011 не показаны в листе оценки. Оценки и достаточность контекста изначально пусты. Проверка чисел и цитат не превращается в семантический балл. Оценку не выполняет Codex или другая языковая модель. Результаты предыдущей модельной диагностики не считаются человеческой оценкой. Отдельное решение о производственном применении возможно только после настоящей ручной проверки и интерпретации её ограничений.
