# ADR 0006 — Явная политика ответимости

## Context

Статический официальный контекст может содержать связанные общие сведения, не подтверждая запрошенный индивидуальный вывод. В полном прогоне Task023A prompt `grounded-answer-v1` ответил на персональную гарантию поступления (`gen-048`) и выбор направления (`gen-059`) вместо требуемого отказа.

## Decision

Ввести `grounded-answer-v2`: перед формированием ответа модель определяет, установим ли запрошенный факт из контекста. Отказ обязателен для индивидуальных прогнозов, неустановленных будущих фактов, личных/оперативных статусов, будущих индивидуальных назначений и персональных рекомендаций при недостатке личных данных. Связанные правила не заменяют ответ на персональный вопрос.

Общие фактические вопросы остаются допустимыми; отдельные слова и разговорная форма не определяют отказ. Все grounding- и prompt-injection-защиты v1 сохраняются. Остаются один retrieval, один вызов генератора, прежний JSON-контракт и фиксированный публичный отказ.

## Alternatives rejected

- Правила по ключевым словам или регулярным выражениям: хрупкая граница и риск ложных отказов.
- Исключения для ID и текста тестовых вопросов: подгонка под датасет.
- Второй классифицирующий LLM-вызов: усложнение текущей архитектуры.
- Изменение retrieval: не устраняет ошибку решения о допустимости персонального ответа.

## Consequences

Ожидается более чёткая граница предметной области и меньше вводящих в заблуждение персональных советов без изменения API. Возможны дополнительные ложные отказы, поэтому принятие требует полного замороженного прогона: 18/18 неподдерживаемых отказов, отсутствие новых supported-отказов и сохранность цитирования. Prompt сам по себе не гарантирует прохождения этих условий.

Task011, Task018 и человеческая оценка Task020 относятся к v1. Они не переименовываются в результаты v2. Фактический статус допуска v2 фиксируется в отчёте 0011; наличие этого ADR не означает успешной приёмки.
