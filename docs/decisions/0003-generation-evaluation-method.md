# ADR 0003: Метод оценки генерации

## Контекст

Качество поиска уже измеряется отдельно. Task009 добавил локальный ответ, но валидные ID цитат не доказывают точность его утверждений.

## Решение

Оценивать неизменный baseline на 42 поддерживаемых вопросах из Task006 и 18 вопросах, требующих отказа. Для каждого вопроса сохранять один ответ и полный диагностический результат. Оценка не меняет поведение приложения.

## Автоматические показатели

Измерять правильность статуса, успешность структурированного ответа, совпадение цитат с ожидаемым источником и страницей, ошибки и время ответа. Знаменатели публиковать явно; ошибки не считать верными ответами.

## Ручные показатели

Человек оценивает фактическую точность, опору на найденный контекст, полноту и поддержку утверждений цитатами по шкале 0–2. Файл обзора сохраняет ответ, цитаты и точный текст цитируемых чанков. Неполный обзор не выдаётся за полный результат.

## Почему без LLM-судьи

Та же модель не должна оценивать достоверность собственных ответов. Структурные и ссылочные совпадения также не заменяют чтения официального текста.

## Последствия

Результаты относятся к текущему активному корпусу СПбГЭУ 2026 года. Слабые показатели фиксируются без скрытой настройки модели, промпта или поиска; улучшения планируются отдельной задачей.
