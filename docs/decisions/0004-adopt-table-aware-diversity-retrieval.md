# ADR 0004: принять поиск по чанкам и строкам таблиц с ограничением PDF-страницы

## Контекст

Базовая оценка Task006 показала ограничения плотного поиска. Task007 добавил reranker и сделал его основным путём. Разбор Task013 указал на потери структуры таблиц PDF. Task014 подтвердил извлечение строк, но общий индекс Task015 вызвал конкуренцию кандидатов. Раздельные каналы Task016 сохранили основной dense top‑20; разбор Task017 выявил насыщение top‑5 соседними строками одной страницы. Правило Task018 восстановило нужные страницы и улучшило замороженные метрики. Ручной обзор Task020 охватил 16 случаев: 9 из 15 содержательных ответов получили максимальные четыре оценки, нулевых оценок не было.

## Решение

Основной режим `reranked` использует один эмбеддинг вопроса BGE‑M3, 20 кандидатов из производственного FAISS и 5 из отдельного индекса строк таблиц. Все 25 оценивает прежний BGE reranker. Финальный отбор идёт по его порядку и допускает не более двух результатов с одной пары `(source_id, page_start)` PDF; HTML не ограничен. Возвращаются до пяти результатов в прежнем публичном формате. Режим `dense` остаётся самостоятельным.

Табличное представление разрешено только для `admission-capacity-pdf`, `entrance-exams-list-pdf` и `tuition-order-128-pdf`. Индекс строится отдельно и проверяется по хешам PDF и производственного индекса. Запрос не обращается к сайту источников и не пересобирает данные. При недоступности или устаревании табличного индекса основной режим сообщает об ошибке.

## Последствия и альтернативы

Схема сохраняет структурированные пары «заголовок → значение» и основной пул dense кандидатов, уменьшает насыщение одной страницей и на замороженных вопросах улучшает Primary R@5 с 70/80 до 74/80, Page R@5 с 47/56 до 49/56. Цена — второй локальный индекс, дополнительная офлайн-команда и строгая проверка совместимости артефактов. Новые PDF не получают табличное представление без отдельной оценки.

Общий расширенный пул Task015 отклонён из-за вытеснения основных кандидатов. Два канала без ограничения страницы Task016 оставляли часть промахов. Повышение score и маршрутизация по тексту вопроса не проверялись как часть принятой схемы.

## Ограничения

Решение проверено на корпусе приёма 2026 года и замороженных вопросах. Неоднозначность эталона `gen-008`, недостаточный контекст `gen-012` и отдельные замечания к генерации и цитированию из Task020 остаются. Попадание в нужный источник само по себе не доказывает точность ответа; принятие поиска не меняет модель генерации.
