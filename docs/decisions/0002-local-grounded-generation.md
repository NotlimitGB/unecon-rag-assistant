# ADR 0002: Локальная генерация ответа по проверенным чанкам

## Решение

Для базового ответа используется существующий `RetrievalService` в режиме `reranked` (или явно выбранном `dense`) и локальная Ollama с моделью `qwen3.5:9b`. На один вопрос приходится один вызов поиска и один вызов модели. Контекст ограничен текущими top-5 без нового ранжирования, сжатия или порогов. Генерация доступна через CLI, без API и frontend.

## Основания

Task007 и Task008 приняли reranker как основной путь выдачи с сохранением происхождения. Локальный генератор позволяет проверить базовый ответ на этих же чанках, не отправляя их внешнему провайдеру. Структурированный вывод содержит только статус, ответ и временные ID цитат. URL, страницу и источник сервис берёт из проверенного результата поиска. При недостатке сведений возвращается фиксированный отказ.

## Ограничения

Ollama и модель нужно установить и загрузить отдельно; ответ зависит от доступности локального сервиса и требует времени и ресурсов на инференс. Валидные ID цитат подтверждают происхождение ссылки, но не доказывают, что ответ точно следует из текста. Качество ответов и отказов требует отдельной ручной и количественной оценки до использования в пользовательском интерфейсе.
